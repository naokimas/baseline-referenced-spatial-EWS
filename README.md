## What is in this repository

The code, the numerical results it produces, and the 6 synthetic networks for the paper.

## Data availability

The study uses 40 networks: 34 empirical and 6 synthetic. The empirical networks are not ours. They
were collected and published by other researchers, and are distributed by public repositories under
those owners' terms. Therefore, we do not redistribute them here, so the 34
corresponding adjacency-matrix files are absent from `data/networks/`.

Readers who want to rerun the empirical part of the study should download each network from its own
source and cite that source. [`data/networks/README.md`](data/networks/README.md) lists every network
with its file name, its number of nodes and edges after our preprocessing, the two repositories we
obtained them from (KONECT and Netzschleuder), the preprocessing steps, and the file format the
scripts expect. Table S1 of the Supplementary Material of the paper describes each network and cites the original study that
collected it.

The 6 synthetic networks were generated by us and are included in `data/networks/`.

**Everything reported as a number in the paper is included**: `data/results/` holds all of it, as
human-readable CSV, already aggregated over all 40 networks.

## Overview of the code

The code is organized as a three-stage pipeline:

1. **Generate equilibrium data** — simulate the stochastic dynamics on each network and record the
   equilibrated node states across a range of the control parameter.
2. **Compute numerical results** — read the equilibrium data and compute the early warning signal (EWS)
   performance measures, saving them as human-readable CSV files.
3. **Plot figures** — read the CSV result files (and, for two figures, the equilibrium data directly)
   and produce the manuscript / SI figures.

```
code/
  common/                              shared definitions, imported by the stage scripts
    model_parameters.py                  constants of the four models; contains no simulation code
    sde_simulator.py                     numba Euler-Maruyama integrator; produced all equilibrium data
    home_range.py                        the home range: control values before the first node tips
    supf.py                              the sup-F structural-change test (non-sequential + sequential)
    supf_temporal.py                     applies that same test to the single-node temporal variance
    require_data.py                      guards the inputs this repository does not ship (see above)
  1_generate_equilibria_with_noise/
    generate_equilibria.py               -> data/equilibria_with_noise/   (not committed)
  2_compute_results/
    compute_spatial_tau.py               -> data/results/results_full.csv, results_half.csv
    compute_sentinel_and_supf.py         -> data/results/sentinel_results.csv
    generate_temporal_samples.py         -> data/temporal_samples/ (not committed)
                                            + data/results/temporal_results.csv
    compute_temporal_stats.py            -> data/results/perpair_tau.csv, perpair_supf.csv
  3_plot_figures/
    fig1_classical_ews.py  fig2_variance_variants.py  fig3_tau_heatmap.py
    fig4_supf_detection.py   fig5_temporal_vs_spatial.py  fig6_sentinel_selection.py
data/
  networks/                   the 6 synthetic adjacency matrices, <net>.npz (scipy sparse);
                              the 34 empirical ones are NOT included -- see networks/README.md
  simulation_parameters.csv   one row per simulation condition: parameters, range, and home range
  results/                    all human-readable numerical results (see below)
  equilibria_with_noise/      NOT included; created by Stage 1 as <model>-<net>-<cparam>-<dir>.npy
                              (100 x N) + .json metadata, plus _manifest.csv summarizing the 400 runs
  temporal_samples/           NOT included; created by generate_temporal_samples.py
figures/                     NOT included; created by the Stage-3 scripts, which write the main-text
                             figures here
Supplementary Material/      NOT included; created by the Stage-3 scripts, which write the SI figures
                             here. The Supplementary Material itself is part of the arXiv paper
theory-spatial-ews/          code for the companion paper (arXiv:2608.15476), with its own README
```

`ROOT` in every script is the repository root; all paths are resolved relative to it, so the scripts can
be run from anywhere (e.g., `python3 code/3_plot_figures/fig3_tau_heatmap.py`).

Requirements: Python 3.9+, `numpy`, `scipy`, `matplotlib`, `numba` (only for `common/sde_simulator.py`,
i.e., only when regenerating the equilibrium data).

### What lives in `common/`, and why

Four definitions are used by more than one stage, so each is written once and imported, rather than
repeated per script:

- **`model_parameters.py`** — the constants of the four dynamical models, each annotated with the
  equation of the Methods it belongs to. No simulation code.
- **`sde_simulator.py`** — the numba Euler-Maruyama integrator that produced every one of the 400
  equilibrium files. The only other place where the model equations are integrated is `simulate()`
  inside `2_compute_results/generate_temporal_samples.py`, which records a time series from a given
  snapshot instead of returning a final state; it imports the same constants, so the numbers used by
  the two integrators cannot diverge.
- **`home_range.py`** — the home range, i.e., the control values from the far end up to just before the
  first node tips. Every EWS in the paper is computed over it, so all four analysis scripts obtain it
  from this one function.
- **`supf.py`** — the sup-F test for a structural change at an unknown breakpoint , in both its non-sequential and sequential forms, together with the Monte-Carlo
  calibration of its null distribution. `supf_temporal.py`
  applies the very same functions to the single-node temporal variance, so the temporal-versus-spatial
  comparison of Fig. 5 is made with one test rather than two similar ones.

A fifth module, **`require_data.py`**, is bookkeeping rather than science. It holds the two checks for
the inputs this repository does not ship: `require_dir()` stops a script whose equilibrium or
temporal-sample directory is absent, naming the script that creates it, and `load_network()` stops
with a pointer to `data/networks/README.md` when an empirical adjacency matrix has not been
downloaded. Neither changes what any script computes when the data are in place.

## Stage 1 — equilibrium data

| Script | Output | What it does |
|---|---|---|
| `code/1_generate_equilibria_with_noise/generate_equilibria.py` | `data/equilibria_with_noise/` | For each of the 40 networks x 10 simulation conditions, integrate the SDE (Euler-Maruyama, with dynamical noise) from the initial state, stepping the control parameter across 100 values, and save the equilibrated node states `x_i*` at each value (`.npy`, shape 100 x N) plus metadata (`.json`: model, control parameter, direction, dt, home-range length, RNG seed, etc.). Reads `data/simulation_parameters.csv` and `data/networks/`. |

This is the only stage that reads the adjacency matrices, and hence the only one blocked by the absent
empirical networks. The script iterates over whatever `.npz` files are present in `data/networks/`, so
on a fresh clone it runs the 6 synthetic networks x 10 conditions and stops there; download the
empirical networks into the same directory to obtain all 400 runs.

A **simulation condition** is (dynamical model, control parameter, direction): double-well / mutualistic /
SIS / gene-regulatory, x coupling *D* or stress *u*, x ascending / descending (10 conditions in total). The
**home range** is the run of control-parameter values from the far end up to, but not including, the first
one at which any node has left its initial state. All EWSs are computed over the home range; see
`code/common/home_range.py`.

**Choosing the control-parameter range.** The 100 control values of a condition must bracket its
transition. The script reads a starting range from `data/simulation_parameters.csv` and, where that
range does not leave a usable home range, re-places it so that the tipping point falls at about 85% of
the range. The range actually used is written back to the `.json` metadata and to `simulation_parameters.csv`.

**`data/simulation_parameters.csv`** is the table of settings referred to in section S4 of the
Supplementary Material of the paper. It has one row per simulation condition (400 rows) and the columns:

| column | meaning |
|---|---|
| `dynamics` | dynamical model: `doublewell`, `mutualistic`, `SIS`, `genereg` |
| `cparam` | control parameter swept: `D` or `u` |
| `direction` | `up` (ascending) or `down` (descending) |
| `network` | code name of the network, matching `data/networks/<network>.npz` and the data-file names |
| `network_name` | display name of the network, as in Table S1 |
| `N` | number of nodes |
| `rng.far` / `rng.near` | ends of the simulation range: the value farthest from the transition, and the value close to or beyond it. 100 evenly spaced control values span this range |
| `deltaT` | time step of the Euler-Maruyama integration |
| `D` | fixed coupling strength, for the rows in which `u` is swept (`NA` otherwise) |
| `u` | fixed stress, for the rows in which `D` is swept (`NA` otherwise) |
| `home_len` | number of control values in the home range |
| `home_boundary` | last control value of the home range, i.e., the one before the first node tips |

The columns appear in this order in the file. The scripts address them by name, never by position.

The file is UTF-8 (one network display name carries an accent) and uses CRLF line endings.

**Random numbers.** Each simulation condition draws its noise from its own block of random-number generator (RNG) seeds, derived
from the condition's identity, and each control value within a condition uses its own seed inside that
block. The noise is therefore independent across networks, models, and sweep directions, and across the
control values of a single sweep. Each run records its seed in its `.json`.

## Stage 2 — numerical results (all saved under `data/results/`)

| Script | Reads | Writes | Used by |
|---|---|---|---|
| `compute_spatial_tau.py` | `equilibria_with_noise/`, `networks/` | `results_full.csv`, `results_half.csv` | Fig 3, Fig S1; Fig 5 reference lines |
| `compute_sentinel_and_supf.py` | `equilibria_with_noise/` | `sentinel_results.csv` | Fig 4, Fig 6; Fig 5 reference lines |
| `generate_temporal_samples.py` | `equilibria_with_noise/`, `networks/` | `data/temporal_samples/` + `temporal_results.csv` | the samples feed `compute_temporal_stats.py` (Fig 5); `temporal_results.csv` is a supporting table, used by no figure |
| `compute_temporal_stats.py` | `data/temporal_samples/` | `perpair_tau.csv`, `perpair_supf.csv` | Fig 5, Figs S2-S4 |

The outputs of this stage are committed, computed over all 40 networks. Rerunning a Stage-2 script
overwrites its CSV with results over whichever networks Stage 1 has produced data for.

### The result files in `data/results/`
- **`results_full.csv` / `results_half.csv`** — mean over the 40 networks of the sign-adjusted Kendall's
  tau' for each (simulation condition x EWS x variant), over the full home range / its second half.
- **`sentinel_results.csv`** — for each sentinel-selection rule x sentinel fraction x condition x EWS, the
  performance measures (tau', non-sequential sup-F detection fraction, sequential detection fraction, and
  lead) averaged over the 40 networks. The all-node case is the rows with `fraction = 1.0`.
- **`temporal_results.csv`** — tau' of the single-node temporal variance for each simulation condition,
  network, and number of temporal samples *L'* (2 to 200), averaged over the 10 randomly chosen nodes of that
  network; 10 x 40 x 199 rows. No figure uses this file: Fig 5 and Figs S2-S4 are drawn from
  `perpair_tau.csv` / `perpair_supf.csv` below. `temporal_results.csv` is nevertheless included, because
  it holds the per-network breakdown behind those aggregated curves, and that breakdown cannot be
  recovered from anything else in this repository: the raw temporal samples from which
  `temporal_results.csv` was computed are not committed and are slow to regenerate. Every network
  contributes exactly 10 nodes, so averaging the tau' of `temporal_results.csv` over the 40 networks
  reproduces the `mean` column of `perpair_tau.csv`. The `std` column cannot be recovered by that
  averaging, because it requires the individual per-node values.
- **`perpair_tau.csv` / `perpair_supf.csv`** — for each condition and *L'*, the mean and standard deviation
  over the 400 (40 networks x 10 nodes) values of tau' (resp. of the non-sequential and sequential sup-F
  success indicators). These drive Fig 5 and Figs S2-S4 (curve = mean, band = mean +/- 1 s.d.).

## Stage 3 — figures

Each script draws one figure of the paper and writes it into `figures/` (main text) or
`Supplementary Material/` (SI), creating those directories if they do not exist. The figure images
themselves are not in this repository; see the published paper for them.

| Script | Draws | Writes into | Reads |
|---|---|---|---|
| `fig1_classical_ews.py` | **Fig 1** | `figures/` | equilibria + networks |
| `fig2_variance_variants.py` | **Fig 2** | `figures/` | equilibria |
| `fig3_tau_heatmap.py` | **Fig 3** and **Fig S1** | `figures/`, `Supplementary Material/` | `results_full.csv`, `results_half.csv` |
| `fig4_supf_detection.py` | **Fig 4** | `figures/` | `sentinel_results.csv` |

The four scripts that read only CSVs — `fig3`, `fig4`, `fig5`, `fig6` — run on a fresh clone and
redraw their figures exactly as published. `fig1` and `fig2` read the equilibrium data, which is not
committed, and their panels are mostly empirical networks, so they need Stage 1 to have been rerun
with those networks in place.

## Reproducing from scratch

0. Obtain the 34 empirical networks and place them in `data/networks/`, as described in
   [`data/networks/README.md`](data/networks/README.md). Skip this to run the pipeline on the 6
   synthetic networks only.
1. `python3 code/1_generate_equilibria_with_noise/generate_equilibria.py` — regenerates
   `data/equilibria_with_noise/` (several hours with all 40 networks; the four largest dominate).
2. Stage-2 scripts. `compute_spatial_tau.py` and `compute_sentinel_and_supf.py` are independent of each
   other and read only the equilibria; `compute_temporal_stats.py` must be run after
   `generate_temporal_samples.py`, which produces its input. `generate_temporal_samples.py` simulates
   the full coupled system with noise for all 400 network-condition pairs and is the slowest step
   (several hours); it writes ~230 MB to `data/temporal_samples/`.
3. Stage-3 scripts, in any order; each reads the CSVs written by stage 2 and rewrites its figure.

Step 3 alone reproduces Figs 3-6 and Figs S1-S4 from the committed CSVs; steps
1 and 2 are needed only to rebuild those CSVs.
